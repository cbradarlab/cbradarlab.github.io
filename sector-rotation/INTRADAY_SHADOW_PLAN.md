# 盤中每分鐘產業輪動 — SHADOW 實作規格

狀態：設計與資料來源驗證階段，**尚未啟用盤中抓取**。

## 資料層
- 正式每日收盤同步獨立保留，絕不改動 CB Radar / XQ0。
- 盤中行情來源需具備合法使用與網站展示權限，上市/上櫃均涵蓋，單筆包含證券代號、交易日期、行情時間、現價、昨收、累積成交量與累積成交金額。
- 不可將 TWSE/TPEx 盤後 OpenAPI 假裝為每分鐘行情；MIS 資訊及第三方行情須先驗證條款、頻率限制與涵蓋率。
- 若無全市場合法來源，先僅支援已獲授權的觀察名單；不得以缺漏樣本排名全市場產業。
- 盤中台灣時間 09:00–13:30 每分鐘產生一次快照，逾時/休市/來源交易日不符則顯示延遲並停止更新。

## 計算口徑
- 產業相對強弱：產業內等權股價報酬中位數或等權平均，扣除同期全市場基準；兩種口徑須標示。
- 產業成交額：同產業各股累積成交金額加總；分鐘增量 = 本分鐘累計 - 上分鐘累計，負值或重置需排除。
- 資金熱度代理：分鐘成交額相對於相同時段歷史基準的比值（資料不足則 HOLD），不稱「淨流入」。
- 真正主動買賣淨額須有逐筆成交方向；外資/投信/自營商每分鐘買賣超不可由價格或成交額推論。
- 缺報價、停牌、股票代碼異常、成交量單位不一致、產業歸屬變更須顯示覆蓋率，低覆蓋率停止排行。

## 上線驗收
1. 實際驗證兩市場盤中報價與來源授權，保留 API schema 證據。
2. 驗證 5 檔上市與 5 檔上櫃的日期、時間、價格、累計量額及單位。
3. 小範圍 SHADOW 每分鐘連續兩個交易日，確認時間差、限流、無跨日重複。
4. 覆蓋率、歷史同時段基準與缺值防護 PASS 後才開啟全市場圖表。
5. GitHub Actions 不適合作為精準每分鐘執行器；需獨立常駐服務或合規行情推送端。靜態 GitHub Pages 僅讀取發布後的快照。
